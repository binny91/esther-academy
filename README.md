# האקדמיה של אסתר

אפליקציית לימוד אישית (PWA) בעברית: בורסה, מסחר, כלכלה, מניות, ניהול חברה וגיאופוליטיקה.
פותחים ב-Safari ← שיתוף ← "הוסף למסך הבית".

## הוספת תוכן
- כל מסלול הוא קובץ ב-`content/<id>.js` שקורא ל-`ACADEMY.addTrack({...})`.
- מוסיפים את ה-id לרשימה ב-`content/index.js` (ולרשימת הקבצים ב-`sw.js` לשימוש אופליין).
- שיעור חדש בסוף מסלול קיים נפתח אוטומטית אחרי שמסיימים את הקודם.
- פורמט גוף שיעור: `## כותרת`, `- נקודה`, `> הדגשה`, `**מודגש**`.

ההתקדמות נשמרת ב-localStorage במכשיר. גיבוי/שחזור דרך ההגדרות.
התכנים ללימוד בלבד ואינם ייעוץ השקעות.
